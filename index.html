Settings

A browser can't run yt-dlp, so search by song/artist name goes through a small keyless relay (a Cloudflare Worker) that reads YouTube's own public search-results page server-side — no API key, no quota. Playback is always YouTube's official embedded player (ad-free direct-stream extraction isn't something a webpage is allowed to do). Pasting a YouTube link or bare video id into Search always works too, relay or not. If you'd rather use your own YouTube Data API v3 key instead, paste it above and clear the relay field.
Output switching uses the browser's audio-output picker (Chrome/Edge only — Firefox and Safari don't support it) and only affects locally-played and Plex audio; a YouTube embed's sound is controlled by YouTube's own player and can't be re-routed from here.
